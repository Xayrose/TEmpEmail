TEMPMAIL — временная почта

Сервис создаёт временные почтовые адреса для получения писем без использования основного почтового ящика. Можно выбрать доступный домен, задать своё имя адреса или сгенерировать случайное.

Письма обновляются автоматически. Адрес действует 60 минут, после чего удаляется. Не используйте временную почту для банков, важных аккаунтов, восстановления паролей и конфиденциальной переписки.

Доступные домены загружаются из подключённых почтовых источников. Интерфейс работает как Telegram Mini App.
